CLI Architecture: pyalex experiments plot

Organizing visualization tools as subcommands of the main experiment script.

Proposed Command Hierarchy
python collaboration_prediction.py plot
├── calibration
│   ├── --predictions-file (JSON)
│   ├── --strategy (e.g., "recency_weighted")
│   └── --output (PNG/PDF)
├── stratified
│   ├── --predictions-file (JSON)
│   ├── --graphml (optional, for network features)
│   ├── --strata (e.g., "productivity", "recency")
│   └── --output (PNG/PDF)
└── diagnostics
    ├── --predictions-file (JSON)
    ├── --top-errors (N)
    └── --output (directory)

Key Design Decisions

  • Decoupled Input: Most plots consume the --predictions-output JSON from the evaluate command, avoiding costly re-evaluation.
  • Optional Graph Context: Advanced stratification (e.g., network centrality) can optionally reload the GraphML file if needed.
  • Strategy Scoping: Since evaluation computes all strategies, plot commands allow filtering to a specific one or generating a comparison.
